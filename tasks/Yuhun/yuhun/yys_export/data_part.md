## 输出格式

转换后的JSON文件结构：

```
{
  "meta": {
    "description": "阴阳师御魂数据 - 从yyx格式转换",
    "count": 9279,
    "source": "yyx格式文件"
  },
  "equips": [
    {
      "位置": 5,
      "类型": "火灵",
      "品质": 6,
      "等级": 15,
      "主属性": {
        "类型": "生命加成",
        "数值": "55.00%"
      },
      "副属性": [
        {
          "类型": "暴击伤害",
          "数值": "6.62%",
          "强化次数": 2,
          "等效强化次数": 1.84
        },
        {
          "类型": "速度",
          "数值": "10.90",
          "强化次数": 4,
          "等效强化次数": 4.04
        }
      ]
    }
  ]
}
```

## 字段说明

### meta（元数据）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| description | string | 数据描述 |
| count | number | 御魂总数 |
| source | string | 数据来源 |

### equips（御魂列表）

每个御魂对象包含以下字段：

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| 位置 | number | 御魂位置（0-5） | 5 |
| 类型 | string | 御魂套装名称 | "火灵" |
| 品质 | number | 御魂品质（6=六星） | 6 |
| 等级 | number | 御魂等级（0/3/6/9/12/15） | 15 |
| 主属性 | object | 主属性对象 | 见下方 |
| 副属性 | array | 副属性数组 | 见下方 |

### 主属性对象

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| 类型 | string | 属性类型中文名 | "生命加成" |
| 数值 | string | 格式化后的数值 | "55.00%" 或 "486" |

### 副属性对象

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| 类型 | string | 属性类型中文名 | "暴击伤害" |
| 数值 | string | 格式化后的数值 | "6.62%" 或 "10.90" |
| 强化次数 | number | 估算的强化次数（1-6） | 2 |
| 等效强化次数 | number | 精确的等效次数 | 1.84 |
