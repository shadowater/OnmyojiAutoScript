# 阴阳师御魂数据格式说明

## 一、输入文件格式（第一个文件）

### 文件结构

```
{
  "御魂ID": {
    "base_r": 1.0,
    "base_rindex": 2,
    "single_attr": null,
    "others": 4435744499331334,
    "rattr": [
      [8, 1.6550796232961362],
      [6, 3.6329297549922854],
      [7, 0.9272466846458338],
      [3, 0.939170474316926]
    ]
  }
}
```

### 字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `base_r` | float | 固定为1.0 |
| `base_rindex` | int | 主属性类型编码（0-4） |
| `single_attr` | int/null | 首领御魂固有属性编码 |
| `others` | int | 64位整数，编码御魂类型ID和其他信息 |
| `rattr` | array | 副属性数组，每个元素为 \[属性编码, 比例值\] |

### rattr 副属性格式

```
[属性编码, 比例值]
```

*   **属性编码**：0-11，对应不同属性类型
*   **比例值**：相对于该属性最大成长值的比例

#### 属性编码表

| 编码 | 英文名称 | 中文名称 | 最大成长值 |

| 3 | HpRate | 生命加成 | 3% |
| 4 | DefenseRate | 防御加成 | 3% |

### base\_rindex 主属性编码

| 编码 | 主属性 | 可能位置 |
| --- | --- | --- |
| 0 | Attack（攻击） | 1号位 |
| 1 | Defense（防御） | 3号位 |
| 2 | Hp（生命） | 5号位 |
| 3 | Speed（速度） | 2号位 |
| 4 | CritRate（暴击） | 6号位 |

### others 字段解码

`others` 由三段 20-bit 拼接而成：

```
others = (prefix << 40) | (suit_id << 20) | equip_id
```

**字段含义**：

```
suit_id  = (others >> 20) & 0xFFFFF
equip_id = others & 0xFFFFF
prefix   = others >> 40
level    = (prefix - 0xC2) / 0x100
```

其中 `prefix` 低 8 位固定为 `0xC2`，高 8 位为御魂等级（0/3/6/7/8/9/12/13/15）。

## 二、换算公式

### 1\. 副属性游戏值计算

**百分比属性**（CritRate, HpRate, AttackRate, DefenseRate）：

```
游戏值 = 比例值 × 3%
```

**暴击伤害**（CritPower）：

```
游戏值 = 比例值 × 4%
```

**速度**（Speed）：

```
游戏值 = 比例值 × 3
```

**固定数值属性**（Attack, Defense, Hp）：

```
游戏值 = 比例值 × 对应最大值
Attack: 27, Defense: 5, Hp: 114
```

### 2\. 等级推断

根据副属性比例总和推断：

| 等级 | 比例和范围 |
| --- | --- |
| 0 | \< 3.8 |
| 3 | 3.8 - 4.5 |
| 6 | 4.5 - 5.5 |
| 9 | 5.5 - 6.5 |
| 12 | 6.5 - 7.5 |
| 15 | ≥ 7.5 |

### 3\. 强化次数计算

```python
平均成长值 = 最大成长值 × 0.9
强化次数 = round(游戏值 / 平均成长值)
等效强化次数 = 游戏值 / 平均成长值
```

**注意**：基础值算1次，满收益为6次（基础1次 + 5次强化）

## 五、已知限制

### 位置推断

优先使用 `others -> equip_id` 解码位置，只有当 `equip_id` 不在映射表中时，才会回退到 `base_rindex` 的位置推断。

### 首领御魂固有属性

首领御魂（土蜘蛛、荒骷髅等）有额外固有属性，编码在 `single_attr` 字段中，但当前映射表不完整。
